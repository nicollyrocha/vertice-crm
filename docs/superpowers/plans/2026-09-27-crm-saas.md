# Vértice CRM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** CRM SaaS multi-tenant B2B em PT-BR, pronto para deploy na Vercel com Neon + Auth.js.

**Architecture:** Next.js 16 App Router. Server Components para leitura e Server Actions para escrita. Toda regra de dados fica em `src/server/*`, isolada por `orgId`, que vem de `requireOrgContext()`. A UI é feita com shadcn/ui + Tailwind v4. O Auth.js v5 usa sessão JWT, e o `proxy.ts` (antigo middleware no Next 16) protege `/app`.

**Tech Stack:** next@16, react@19, next-auth@5.0.0-beta, @auth/drizzle-adapter, drizzle-orm@0.45 + drizzle-kit, @neondatabase/serverless, tailwindcss@4, shadcn, zod@4, bcryptjs, resend, @vercel/blob, recharts@3, @dnd-kit, sonner, next-themes, cmdk, vitest, @playwright/test.

Spec: `docs/superpowers/specs/2026-09-27-crm-saas-design.md`

## File Structure

```
src/
  config/site.ts                 # nome da marca, URLs, planos de preço, nav
  env.ts                         # validação Zod das env vars
  proxy.ts                       # proteção de rotas (Next 16)
  auth.ts                        # config Auth.js (providers, callbacks)
  db/
    index.ts                     # client drizzle + neon-http
    schema.ts                    # todas as tabelas
    seed.ts                      # dados demo
  lib/
    utils.ts                     # cn()
    format.ts                    # BRL, datas, iniciais
    tokens.ts                    # geração/hash de tokens
    password.ts                  # hash/verify bcrypt
    action.ts                    # tipo ActionResult + helpers
    validations/*.ts             # schemas Zod (auth, account, crm)
  server/
    context.ts                   # requireUser, requireOrgContext, requireRole
    permissions.ts               # regra de papéis (pura, testável)
    rate-limit.ts
    email/{send.ts,templates.ts}
    data/{dashboard,deals,contacts,companies,activities,notes,pipeline,members,search,timeline}.ts
    actions/{auth,account,org,deals,contacts,companies,activities,notes,pipeline,members}.ts
  components/
    ui/*                         # shadcn
    marketing/*                  # seções da landing
    app/*                        # sidebar, topbar, command menu, org switcher, etc.
    crm/*                        # kanban, tabelas, forms, timeline
  app/
    (marketing)/{page,pricing,terms,privacy}
    (auth)/{login,signup,forgot-password,reset-password,verify-email,invite/[token]}
    onboarding/
    app/{page,deals,contacts,companies,activities,settings/*}
    api/auth/[...nextauth]/route.ts
tests/unit/*.test.ts
tests/e2e/*.spec.ts
```
